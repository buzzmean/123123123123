# VIONIX — сайт премиального компьютерного клуба

Одностраничный сайт для компьютерного клуба **VIONIX** (г. Ставрополь). Проект собран на **React + TypeScript + Vite + Tailwind CSS**.

## Структура

- `index.html` — точка входа, SEO-мета-теги, Open Graph, favicon.
- `src/App.tsx` — корневой компонент.
- `src/components/` — секции сайта и переиспользуемые компоненты.
- `src/data.ts` — данные зон, цен, оборудования, галереи и контактов.
- `src/utils/` — утилиты (`cn`, маска телефона).
- `public/images/` — изображения сайта.

## Запуск на Windows 11

1. Установите **Node.js** LTS с официального сайта: https://nodejs.org/ (если ещё не установлен).
2. Распакуйте архив `VIONIX-SITE-KIMI.zip` в любую папку.
3. Откройте папку проекта в терминале (Проводник → ПКМ → "Открыть в Терминале" или используйте `cmd`/`PowerShell`).
4. Установите зависимости:

   ```bash
   npm install
   ```

5. Запустите локальный сервер разработки:

   ```bash
   npm run dev
   ```

6. В терминале появится адрес, например:

   ```
   Local: http://localhost:5173/
   ```

   Откройте этот адрес в браузере.

## Сборка production-версии

```bash
npm run build
```

Готовый сайт появится в папке `dist/`. Файл `dist/index.html` можно открыть локально или разместить на хостинге.

## Особенности

- Премиальный минималистичный дизайн в тёплых графитово-шоколадных тонах.
- 5 игровых зон с карточками, характеристиками и ценами.
- Интерактивный прайс-лист с переключением продолжительности.
- Раздел оборудования, галерея с лайтбоксом, форма бронирования с валидацией и маской телефона.
- Адаптивная вёрстка для десктопа, планшетов и смартфонов.
- Учёт `prefers-reduced-motion`.

## Контакты-заглушки

Адрес, телефон, email и режим работы в разделе "Контакты" указаны как редактируемые заглушки. Замените их в файле `src/data.ts` перед публикацией.
