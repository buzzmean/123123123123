# VIONIX — сайт премиального компьютерного клуба (Ставрополь)

Современный адаптивный сайт компьютерного клуба VIONIX: 36 игровых ПК, зона PlayStation 5,
пять категорий игровых мест (STANDARD, ARENA, BOOTCAMP, DUO 27', DUO 24'), интерактивный
прайс-лист, галерея, демонстрационная форма бронирования и раздел контактов.

## Технологии

- React 19 + TypeScript
- Vite 7
- Tailwind CSS 4
- lucide-react (иконки)

## Запуск проекта на Windows 11

1. **Установите Node.js**, если он ещё не установлен.
   Скачайте LTS-версию с официального сайта https://nodejs.org и установите с настройками по умолчанию.
   Проверить установку можно командой в PowerShell или «Командной строке»:
   ```
   node -v
   npm -v
   ```

2. **Откройте папку проекта.**
   Распакуйте архив `VIONIX-SITE-KIMI.zip` в удобное место (например, `C:\Projects\vionix`)
   и откройте эту папку в «Командной строке», PowerShell или терминале VS Code.

3. **Установите зависимости** командой:
   ```
   npm install
   ```

4. **Запустите сайт в режиме разработки**:
   ```
   npm run dev
   ```
   После запуска в терминале появится локальный адрес, обычно:
   ```
   http://localhost:5173
   ```
   Откройте этот адрес в браузере.

5. **(Опционально) Сборка production-версии:**
   ```
   npm run build
   ```
   Собранный сайт появится в папке `dist/`. Посмотреть собранную версию локально можно командой:
   ```
   npm run preview
   ```

## Структура проекта

```
src/
  components/      — секции и переиспользуемые UI-компоненты
  data/             — данные о зонах, оборудовании и галерее
  utils/            — вспомогательные функции
  App.tsx           — сборка страницы из секций
  index.css         — дизайн-токены и глобальные стили (Tailwind CSS 4)
public/
  images/           — изображения клуба, зон и PS5-зоны
  favicon.svg       — favicon сайта
```

## Важно перед публикацией

В разделе «Контакты» (`src/components/Contacts.tsx`) используются поля-заглушки
(адрес, телефон, режим работы, email, ссылки на соцсети) — замените их на реальные данные
клуба VIONIX перед запуском сайта в продакшн. Карта в этом разделе — заглушка под будущую
интеграцию с Яндекс.Картами или Google Maps.

Форма бронирования (`src/components/Booking.tsx`) — демонстрационная: после отправки
показывается подтверждение заполнения, но заявка не передаётся в реальную систему клуба.
Для реальной интеграции потребуется подключить бэкенд или сторонний сервис приёма заявок.
